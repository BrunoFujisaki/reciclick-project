## 📌 Introdução  
A administração eficaz dos resíduos sólidos representa um desafio crescente em áreas urbanas, exigindo abordagens que combinem:  
- **Sustentabilidade**  
- **Inovação tecnológica**  
- **Engajamento popular**  

Este projeto propõe:  
1. **Mapa interativo** de pontos de reciclagem (ecopontos e coleta seletiva) na cidade de **Maringá/PR** (dados fictícios).  
2. **Gamificação** da reciclagem (sistema de pontuação para incentivar descarte correto).  

---

## 🎯 Objetivo  
Promover a sustentabilidade por meio de tecnologias acessíveis:  
- Facilitar o acesso a práticas sustentáveis via mapa interativo.  
- Estimular comportamentos conscientes através da gamificação.  

---

## ⚙️ Método  
### Ferramentas Desenvolvidas  
- **Mapa Interativo:**  
  - Biblioteca **Leaflet** para visualização geográfica.  
  - Integração com **API ViaCEP** e **Nominatim** para busca de endereços.  
- **Gamificação:** Sistema de recompensas por reciclagem.
